# BakaPatch

A very smol collection of QoL features (held together with tape) for [Archive of Our Own](https://archiveofourown.org/).

**ScribbleHub support coming soon™** 👀

## Features

1. Very fancy UI
2. Very smart
3. Very awesome
4. Very sexy

## Installation

1. Download the latest release from the [Releases](https://github.com/VibeCoderClone/bakapatch/releases) page.
2. Install a browser extension that lets you run and manage userscripts.
3. Install BakaPatch into your preferred browser extension.
4. Open AO3.
5. Enjoy the improvements

> BakaPatch is still being actively worked on, so things may explode.

## Why?

I am in love with AO3, but the UI is way too confusing (for me — I am dumb) and it's missing a few little features that I personally find useful.

So I decided to write a user script for y'all. (*With Claude*)
